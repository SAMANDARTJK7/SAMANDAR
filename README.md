# Трейдинг Дневник (React Native)

Минималистичное мобильное приложение в темной теме для ведения журнала сделок.

## Функционал
- Ввод суммы сделки (прибыль или убыток).
- Положительные суммы отображаются зеленым, отрицательные — красным.
- Список всех записей с датой и временем.
- Удаление любой записи.
- Расчет и отображение общего баланса за все время.

## Запуск
```bash
npm install
npm run start
```

Далее откройте проект в Expo Go (Android / iOS) или запустите веб-версию через `w` в терминале Expo.
