# SAMANDAR CREATOR

Одностраничный сайт-портфолио Самандара Алишера, работающий в бизнес-режиме и демонстрирующий услуги разработчика, достижения и способы связи.

## Структура проекта

- `index.html` — основная страница сайта.
- `assets/css/style.css` — стили оформления и адаптивная сетка.
- `assets/js/main.js` — интерактивность (мобильное меню, модальные окна, обработка формы, переключение бизнес-режима).

## Как запустить

Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge). Все ресурсы подключены локально, интернет нужен только для загрузки шрифта Google.

## Особенности

- Переключение «Бизнес-режима» для активации акцентного оформления.
- Модальные окна с описанием кейсов.
- Анимированные бизнес-метрики при прокрутке.
- Валидация контактной формы на стороне клиента.
- Кнопка «Назад наверх» и адаптивная навигация для мобильных устройств.
